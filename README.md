Lumière Hair Studio & Wig Boutique (Lusaka, Zambia)

A luxury web application and e-commerce platform designed for a premier hair studio and human hair vendor based in Lusaka, Zambia. The project focuses on high-conversion booking flows, luxury raw hair/wig catalog showcases, and localized payment integrations.

🌟 Key Features

Localized Pricing & Currency: Displayed natively in Zambian Kwacha (ZMW) with clear tiered pricing brackets (ZMW 1,500 – ZMW 4,000).

Zambian Mobile Money Integration: Prepared checkout flows supporting Airtel Money and MTN Mobile Money alongside standard card payments.

Specialized Service & Product Catalog:

Ready-to-wear glueless wigs & HD frontal units.

Premium raw human hair bundles and weave installations.

Custom wig maintenance, bleaching knots, and reviving treatments.

Appointment Booking System: Seamless scheduling for in-studio lace installs, custom fittings, and consultations in Lusaka (Mass Media / Kabulonga area).

Social Proof & Media Grid: Live Instagram integration highlighting client transformations, lace melts, and customer reviews.

🎨 Design System & Aesthetics

Vibe: Warm Luxury, Afro-centric Minimalist, and High-Status Glam.

Palette:

Primary Accent: Terracotta / Rust Copper (#C46D4E)

Background: Warm Off-White / Cream (#FBF8F5)

Surface Cards: Soft Nude Beige (#F3ECE7)

Typography: Deep Espresso (#2B231F)

Typography: Serif headlines (Cormorant Garamond / Playfair Display) paired with clean sans-serif body text (Plus Jakarta Sans).

🚀 Quick Start

Prerequisites

Node.js (v18.0 or higher recommended)

NPM / Yarn / PNPM

Installation

# Clone the repository
git clone https://github.com/your-username/lumiere-hair-studio-lusaka.git

# Navigate into the project directory
cd lumiere-hair-studio-lusaka

# Install dependencies
npm install

# Start development server
npm run dev


📱 Mobile Responsiveness

The platform is optimized for mobile-first usage to cater to users accessing the store via Instagram link-in-bio traffic and smartphones across Zambia.
